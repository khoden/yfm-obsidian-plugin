# YFM Preview

Откройте командную палитру и выполните **YFM Preview: Toggle preview**.
Измените этот абзац и дождитесь сохранения: панель обновится через 500 мс после изменения файла.

## Примечания

{% note info "Проверка note" %}

Внутри работает **Markdown**, [внешняя ссылка](https://diplodoc.com) и список:

- Первый пункт.
- Второй пункт.

{% endnote %}

{% note warning "Ограничения прототипа" %}

YFM includes, переменные, условия и специфичная разметка Obsidian не поддерживаются.

{% endnote %}
